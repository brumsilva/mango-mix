# Mango Mix Franquias

Landing page oficial de captação de interessados na franquia Mango Mix.

## Tecnologias

- React e TypeScript
- Vite e Tailwind CSS
- Framer Motion
- Supabase para receber os formulários de interesse

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm test
npm run build
```

As variáveis `VITE_SUPABASE_URL` e `VITE_SUPABASE_PUBLISHABLE_KEY` devem estar configuradas no ambiente.
